Project Management REST API

This RESTful API lets users manage their projects using HTTP methods. It supports POST, GET, PUT, and DELETE requests to create, retrieve, update, and delete project data from the database.

Possible Endpoints

Method Path Description
POST /projects Create a new project and save it into db
GET /projects Retrieve all projects in a list
GET /projects/:id Retrieve projects by ID
GET /projects/by-name/:projectName Retrieve projects by name
PUT /projects/:id Update project info by ID
DELETE /projects/:id Delete a project by ID
DELETE /projects Delete all projects from db
